# Choosing between contemporaneous and dynamic kernels

MCMSEM offers two moment kernels. Neither is a generally superior version of
the other. The choice states where causal time lives in the model.

## Public API and migration

```r
MCMmodel(ds, kernel = "contemporaneous") # default
MCMmodel(ds, kernel = "dynamic")
```

`kernel = "static"` is a supported, silent alias for `"contemporaneous"`.
Legacy summaries and models without kernel metadata are treated as
contemporaneous. Kernel names are otherwise matched exactly; partial spellings
are rejected.

## Contemporaneous Structural MCMSEM

Contemporaneous Structural MCMSEM assumes that measured variables can be
represented by structural equations at one conceptual occasion, such as
`Y = beta X + epsilon_Y`. The coefficient is interpreted interventionally:
replacing the structural equation for `X` by `X = x` changes the value generated
for `Y`. The model contains no explicit transition from `t` to `t + 1`. Prior
history, adaptation, feedback, and equilibrium processes are outside the model
and are absorbed into the variables, disturbances, or interpretation of the
coefficient. Higher-order moments may identify the direction of a
contemporaneous structural relation, but they do not create a temporal order
that the model does not contain.

Choosing this kernel assumes that a same-occasion structural intervention is
scientifically meaningful at the variables' measurement scale. It is most
defensible when one variable plausibly acts before another within the
measurement window, or when the path is interpreted as an equilibrium or
integrated contemporaneous response. If substantial reciprocal dynamics occur
inside the measurement interval, a contemporaneous path may summarize those
integrated dynamics rather than represent a single mechanistic transition.

The second-order propagation remains

```text
M2 = Fm (I - A)^-1 S (I - A)^-T Fm^T
```

with the existing third- and fourth-order propagation unchanged.

## Stationary Dynamic MCMSEM

Stationary Dynamic MCMSEM assumes that the system evolves through repeated,
time-homogeneous transitions,

```text
z[t] = B z[t-1] + epsilon[t].
```

An entry such as `beta_X_to_Y` represents the effect of `X[t]` on `Y[t+1]` at
the chosen lag. Although the model may be fitted to one cross-sectional
stationary distribution, time has not been conceptually integrated out.
Stationarity specifies how the unobserved history accumulates into that
distribution:

```text
z[t] = epsilon[t] + B epsilon[t-1] + B^2 epsilon[t-2] + ... .
```

For cumulant order `r`, the production kernel solves

```text
C_r = (I - B^(x r))^-1 D_r,
```

where `B^(x r)` denotes the r-fold Kronecker power. The package uses linear
solves, not explicit inverses. `D2` is fixed to the identity. `D3` and `D4` have
one freely estimated diagonal innovation cumulant per state and zero mixed
innovation cumulants. These restrictions encode the fixed innovation scale and
mutual independence assumptions.

Choosing this kernel commits the analyst to a temporal resolution and to
repeated stable transitions: the same `B` and innovation distribution operate
across time, innovations are serially independent, and the process has reached
stationarity. A one-day transition and a one-year transition are not the same
parameter. The dynamic model is mechanistically more explicit, but relies on
stronger assumptions about lag structure, stationarity, and omitted
intermediate dynamics.

## Gaussian residual or random-intercept covariance

The observed state may contain an independent Gaussian component:

```text
y[t] = z[t] + G,   G ~ N(0, Psi_G).
```

There is one component per trait, loading one on that trait, and `Psi_G` may be
full. MCMSEM parameterizes it as `L_G L_G^T`, with exponentiated Cholesky
diagonals, so every optimizer state produces a positive-definite covariance.
This component changes total covariance but contributes no third or fourth
cumulant. Since MCMSEM fits raw fourth central moments, the package reconstructs

```text
M4[i,j,k,l] = K4[i,j,k,l]
             + Sigma[i,j] Sigma[k,l]
             + Sigma[i,k] Sigma[j,l]
             + Sigma[i,l] Sigma[j,k],
```

using the total covariance `Sigma = C2 + Psi_G`.

## Common-gamma residual confounder

When one shared skewed source is scientifically plausible, use
`residual_family = "common_gamma"` instead of the Gaussian residual:

```r
model <- MCMmodel(
  ds, kernel = "dynamic", residual_family = "common_gamma"
)
```

The observed state is `y[t] = z[t] + lambda * U`, where
`U = (G - alpha) / sqrt(alpha)` and `G` has a gamma distribution with shape
`alpha` and unit scale. Thus `U` is centered and has variance one. The factor
contributes

```text
C2_U = lambda lambda'
C3_U = (2 / sqrt(alpha)) lambda^(x3)
K4_U = (6 / alpha) lambda^(x4)
```

where `^(xr)` denotes the order-`r` outer-product tensor. Loadings may be
positive or negative; `shape_Gamma` is constrained positive. This is an
additive confounder at the stationary marginal level and is not propagated
through `B`. It replaces the Gaussian residual in the current API. The fitted
loadings and shape are in `fit$dynamic$common_gamma`, and the three cumulant
components are in `fit$dynamic$residual_M2`, `residual_M3`, and `residual_K4`.

For two variables, the common-gamma factor has the same raw parameter count as
the full Gaussian covariance (two loadings and one shape), but it is far more
restrictive: covariance must be rank one and the same loadings and shape must
also reproduce co-skewness and co-kurtosis. Inspect loss, Jacobian rank and
conditioning, admissible multistarts, and sensitivity to innovation constraints
rather than choosing it only because it is non-Gaussian.

## WLS weighting and asymptotic standard errors

The fitted vector contains unique raw central moments through order four. With
residual `r = s - sigma(theta)`, the dynamic quadratic criterion is `r' W r`.
`MCMdatasummary(..., prep_asymptotic_se = TRUE)` prepares
`Omega = Var(s)` using central-moment influence functions that account for the
estimated sample means.

`moment_weighting` may be `"identity"`, `"diagonal"` (inverse marginal moment
variances), or `"full"` (a regularized inverse of `Omega`). If `Delta` is the
Jacobian of the implied moments, identity and diagonal weighting default to
the robust sandwich covariance

```text
(Delta' W Delta)^-1 Delta' W Omega W Delta (Delta' W Delta)^-1.
```

Full WLS defaults to the efficient covariance `(Delta' W Delta)^-1`.
`se_correction = "robust"` can request the sandwich with any weight matrix.
Because `Omega` is stored as `Var(s)`, its `1/N` scaling is already present.
The reported SEs for a derived residual covariance use a delta-method Jacobian:
`Psi_G = L_G L_G'` for Gaussian residuals and `lambda lambda'` for the
common-gamma factor. Factor loading and shape SEs are reported with the ordinary
parameter table.

These are local unconstrained Wald approximations. Inspect Jacobian rank and the
reported information condition number, and be cautious when stationarity or
parameter bounds are active. The bundled 50-replication calibration shows close
ASE/empirical-SD agreement for an eight-parameter overidentified model, but
strongly conservative SEs for the weakly identified 11-parameter bivariate
model with a free Gaussian covariance (`inst/validation/README.md`).

## Identification and diagnostics

With two variables, unique moments through order four number `3 + 4 + 5 = 12`.
The full bivariate dynamic model estimates four entries of `B`, two third
cumulants, two fourth cumulants, and either three Gaussian covariance
parameters or two common-gamma loadings plus one shape: 11 parameters and one
nominal overidentifying degree of freedom. Parametric innovation constraints
can increase overidentification, but do not by themselves prove identification.

Counting is not a proof of global identification. Generic identification
depends on useful and nondegenerate non-Gaussian innovation cumulants, mutual
independence, fixed innovation scale, stationarity, distinct source cumulant
profiles, and the absence of unmodelled non-Gaussian confounding. Similar or
near-Gaussian sources can yield weak identification or several low-loss states.
Use multiple starts and inspect all-start diagnostics. `MCMdiagnostics(fit,
jacobian = TRUE)` adds a numerical Jacobian-rank check at the fitted solution.

The original MCM-SEM framework is described by Zenab Tamimy, Elsje van Bergen,
Matthijs D. van der Zee, Conor V. Dolan, and Michel G. Nivard (2022),
[*Multi Co-Moment Structural Equation Models: Discovering Direction of
Causality in the Presence of
Confounding*](https://doi.org/10.31235/osf.io/ynam2), SocArXiv. The
cumulant-identification framework and discrete Lyapunov formulation underlying
the dynamic kernel build on Cecilie Olesen Recke, Sarah Lumpp, Nataliia
Kushnerchuk, Janike Oldekop, Jiayi Li, Jane Ivy Coons, and Elina Robeva (2026),
[*Identifiability in Graphical Discrete Lyapunov
Models*](https://arxiv.org/abs/2601.21818), arXiv preprint arXiv:2601.21818. No
journal publication status is claimed for the latter.

## Worked longitudinal comparisons

### Controlled simulation

The first example creates four waves from a stationary bivariate VAR(1) with
known transition matrix. The mutually independent innovations have mean zero,
unit variance, and distinct non-Gaussian distributions.

```r
library(MCMSEM)
library(lavaan)
set.seed(20260730)

n <- 20000L
B_true <- matrix(c(0.55, 0.16, -0.12, 0.45), 2, 2, byrow = TRUE)
state <- matrix(0, n, 2)
panel <- array(NA_real_, c(n, 2, 4))
innovation <- function(n) {
  cbind(rexp(n) - 1, (rchisq(n, 5) - 5) / sqrt(10))
}
for (tt in seq_len(204L)) {
  state <- state %*% t(B_true) + innovation(n)
  if (tt > 200L) panel[, , tt - 200L] <- state
}
wide <- data.frame(
  X1 = panel[, 1, 1], Y1 = panel[, 2, 1],
  X2 = panel[, 1, 2], Y2 = panel[, 2, 2],
  X3 = panel[, 1, 3], Y3 = panel[, 2, 3],
  X4 = panel[, 1, 4], Y4 = panel[, 2, 4]
)
```

Fit one transition matrix to all three lags with a CLPM:

```r
clpm <- "
  X2 ~ x_ar*X1 + y_to_x*Y1
  X3 ~ x_ar*X2 + y_to_x*Y2
  X4 ~ x_ar*X3 + y_to_x*Y3
  Y2 ~ y_ar*Y1 + x_to_y*X1
  Y3 ~ y_ar*Y2 + x_to_y*X2
  Y4 ~ y_ar*Y3 + x_to_y*X3
  X1 ~~ Y1
  X2 ~~ Y2
  X3 ~~ Y3
  X4 ~~ Y4
"
clpm_fit <- sem(clpm, data = wide, estimator = "MLR",
                meanstructure = TRUE)
```

Then give dynamic MCMSEM only the final marginal cross-section:

```r
final <- wide[c("X4", "Y4")]
names(final) <- c("X", "Y")
ds <- MCMdatasummary(
  final, scale_data = FALSE, prep_asymptotic_se = TRUE,
  use_skewness = TRUE, use_kurtosis = TRUE
)
model <- MCMmodel(
  ds, n_latent = 0, kernel = "dynamic",
  gaussian_residual = FALSE
)
model <- MCMedit(model, "B", c(1, 1), "x_ar")
model <- MCMedit(model, "B", c(1, 2), "y_to_x")
model <- MCMedit(model, "B", c(2, 1), "x_to_y")
model <- MCMedit(model, "B", c(2, 2), "y_ar")
fit <- MCMfit(
  model, ds, compute_se = TRUE,
  optimizers = c("rprop", "lbfgs"), optim_iters = c(750, 40),
  learning_rate = c(0.01, 0.2),
  moment_weighting = "diagonal", se_correction = "robust",
  n_starts = 20, seed = 20260730, verbose = FALSE
)
MCMdiagnostics(fit, jacobian = TRUE)
```

| Path (`current <- lagged`) | Truth | CLPM estimate (SE) | Dynamic estimate (robust SE) |
|---|---:|---:|---:|
| X <- X | 0.550 | 0.550 (0.003) | 0.555 (0.014) |
| X <- Y | 0.160 | 0.162 (0.004) | 0.147 (0.046) |
| Y <- X | -0.120 | -0.117 (0.003) | -0.111 (0.028) |
| Y <- Y | 0.450 | 0.446 (0.004) | 0.462 (0.014) |

The CLPM had robust CFI = 1.000, RMSEA = 0.000, and SRMR = 0.003. The
dynamic fit had loss 0.000459, spectral radius 0.522, df = 4, Jacobian rank
8/8, information condition 1.81e4, and 20/20 admissible starts. This close
recovery is expected because the simulation exactly matches both estimators'
assumptions.

Fixed unit innovation variances make scale part of the identifying model.
`scale_data = FALSE` preserves the supplied measurement scale. Scaling remains
available, but changes the target parameterization.

### SIPP real-data illustration

The real-data example now uses the U.S. Census Bureau's public-use
[2014 SIPP panel](https://www.census.gov/programs-surveys/sipp/data/datasets/2014-panel.html),
whose four waves cover 2013--2016. The repository contains only a 437 KB
derived matrix with four waves of transformed log earnings and hours. It
contains no identifiers, demographics, survey weights, or original Census
columns; the large public-use source files are not vendored. The exact filters,
transformation, sample counts, checksum, and official links are recorded in
[`inst/extdata/README.md`](https://github.com/MichelNivard/MCMSEM/blob/master/inst/extdata/README.md).

Every method uses the same fixed affine scale. Wave 1 has the largest jointly
observed sample and is therefore supplied to dynamic MCMSEM:

| Year | Complete N | Earnings variance | Hours variance | Covariance |
|---:|---:|---:|---:|---:|
| 2013 | 22,049 | 4.000 | 4.000 | 2.031 |
| 2014 | 15,787 | 4.192 | 4.170 | 2.179 |
| 2015 | 12,190 | 4.012 | 4.205 | 2.087 |
| 2016 | 10,446 | 4.057 | 4.156 | 2.166 |

The similar but non-identical moments make wave 1 a precision choice under
approximate stationarity, not proof of stationarity. The first comparison is an
observed-score CLPM against the plain dynamic kernel with
`residual_family = "none"`:

| Path | CLPM | Plain dynamic MCMSEM |
|---|---:|---:|
| Earnings autoregression | 0.628 (0.011) | 0.980 (0.026) |
| Hours to later earnings | 0.063 (0.008) | -0.315 (0.121) |
| Earnings to later hours | 0.124 (0.007) | 0.521 (0.112) |
| Hours autoregression | 0.476 (0.009) | 0.486 (0.113) |

The plain fit had loss 0.3659, spectral radius 0.800, df = 4, rank 8/8,
information condition $6.94 \times 10^6$, and 10/40 admissible starts. The
earnings autoregression was effectively at its 0.98 upper bound. The
disagreement with the CLPM and the boundary warning are visible rather than
treated as a scaling artifact.

The second comparison separates stable heterogeneity. The RI-CLPM uses repeated
measurements to identify correlated random intercepts.
`residual_family = "gaussian"` gives MCMSEM an additive Gaussian residual
covariance that is conceptually analogous, although its temporal stability is
assumed rather than observed:

| Path | RI-CLPM within person | Dynamic + Gaussian residual | Dynamic + common-gamma residual |
|---|---:|---:|---:|
| Earnings autoregression | 0.105 (0.024) | 0.627 (0.091) | 0.676 (0.032) |
| Hours to later earnings | 0.051 (0.012) | 0.127 (0.104) | 0.075 (0.052) |
| Earnings to later hours | 0.009 (0.015) | 0.465 (0.116) | 0.422 (0.030) |
| Hours autoregression | 0.165 (0.017) | 0.591 (0.163) | 0.651 (0.036) |

The Gaussian MCMSEM fit had loss 0.1004, df = 1, rank 11/11, and information
condition $1.17 \times 10^8$. Its residual covariance was
`matrix(c(1.842, 0.450, 0.450, 0.421), 2)`, implying correlation 0.511.
The common-gamma analysis used signed-gamma innovation constraints to increase
nominal df from one to three. Its common shape was 153.8 (SE 398.2), implying
skewness 0.161 (SE 0.209) and excess kurtosis 0.039 (SE 0.101). Together with
an information condition of $7.29 \times 10^{10}$, this does not provide
reliable evidence of non-Gaussian confounding.

With innovation cumulants left free, an optional grid found a competing
one-df basin with loss 0.00024 and shape 0.489 (SE 0.087), but the hours loading
was only -0.064 (SE 0.037). It represents an earnings-specific skewed residual
rather than a convincing shared confounder. The README and validation script
report both specifications because the conclusion is constraint-dependent.

The simulation proves the estimators can converge when their assumptions and
estimands coincide. They need not converge in real data: the CLPM observes
transitions, the RI-CLPM observes the repeated within/between decomposition, and
MCMSEM identifies both from marginal higher moments and distributional
assumptions. The full executable analysis is in
[`inst/validation/longitudinal_clpm_example.R`](https://github.com/MichelNivard/MCMSEM/blob/master/inst/validation/longitudinal_clpm_example.R).

### How to choose and evaluate

1. A CLPM targets observed-score transitions; an RI-CLPM targets transitions
   among within-person deviations after stable between-person differences are
   removed. Pick the estimand before comparing coefficients.
2. Use `residual_family = "gaussian"` only when an independent stable Gaussian
   component is scientifically plausible. In `p` variables it adds
   `p(p + 1)/2` parameters and can sharply weaken identification.
3. Do not select on training loss alone. Inspect nominal df, held-out moment
   loss where feasible, Jacobian rank, information condition, spectral radius,
   active bounds, admissible starts, and stability of substantive paths across
   specifications.
4. Treat agreement across CLPM, RI-CLPM, and dynamic MCMSEM as triangulation,
   not an automatic validity test: they use different information and generally
   have different estimands.

## Current support and limitations

The dynamic kernel currently supports:

- two or more observed variables;
- a stationary VAR(1);
- independent innovations with fixed unit variances;
- diagonal innovation third and fourth cumulants;
- an optional full Gaussian residual covariance;
- alternatively, one common-gamma residual factor with signed loadings;
- covariance, co-skewness, and raw co-kurtosis;
- identity, diagonal, or full WLS moment weighting and asymptotic robust or
  efficient SEs;
- torch autograd, CPU/GPU device selection, bounds, multi-start fitting, common
  result objects, model comparison, summaries, and plots.

Latent-state measurement models are not yet implemented. Dynamic WLS and SEs
currently exclude analysis weights and require mean-corrected moment covariance
metadata produced by MCMSEM 0.27.0 or later. The Kronecker system has dimension
`p^r`, so fourth-order models become expensive as the number of states grows.

## Continuous time and future models

Both kernels can approximate richer continuous-time systems. One such model is

```text
dz(t) = A z(t) dt + dL(t),
```

where `A` contains rates of change and `L(t)` supplies Gaussian or non-Gaussian
shocks. At observation interval `Delta`, the discrete transition is
`B(Delta) = exp(A Delta)`. Discrete cross-lagged effects therefore depend on the
sampling interval and may combine direct and indirect evolution between
observations.

Natural future extensions include continuous-time cumulant kernels, VAR(q),
models with both contemporaneous and lagged paths, nonlinear or regime-switching
dynamics, nonstationary transitions, latent state/measurement-error models,
non-Gaussian confounders, and interventions defined over trajectories rather
than single time points.
